# Statistics repairs — 11 September 2026

Follow-up to [the full audit](QA_STATISTICS_2026-09-11.md). The original audit and failing evidence remain available; this report records the corrected behavior and verification.

The database repair restored **50 missing winner records**, corrected **52 wrong champions**, and removed **20 manager attributions belonging to the wrongly listed clubs**. All other rows in the twelve audited public tables are unchanged. All seven site datasets were rebuilt from the repaired database.

## Historical cup recovery

The investigation found that early domestic cup finals had two legs. Selecting the higher score from the last match alone is insufficient. The sync now checks the preceding round and combines both legs only when the competition, season, round, and pair of finalists match. A single-match final requires valid semifinal evidence. Cached source responses are reused; existing finished matches are not fetched again. Penalty outcomes and mutual walkovers require explicit source evidence.

The sync also prevents the same final being assigned to different seasons, clears a former winner's country when club identity changes, and exposes unresolved outcomes in regular refreshes. Actual samples verify domestic and Masters match types. Seasonal ArenaHub tournaments retain their dedicated ingestion route.

All 49 missing historical main-cup winners have decisive aggregate scores in CHPP's captured final and first-leg responses. A separate Iranian Alborz Cup S38 final has an explicit mutual-walkover event: neither club fielded nine players. That response identifies no winning side, so it cannot justify adding a champion.

The Supporter Week Trophy S11 winner is Beta Broncos, corroborated by the [tournament history table](https://wiki.hattrick.org/wiki/Supporter_Week) and a [participant's season-68 record](https://wiki.hattrick.org/wiki/CPAM_FC_Supporter_Week_Trophy). Historical team and manager IDs must remain unknown unless separately proved.

That result is now included in the normal seasonal importer. Replaying the retained source preserves stronger identities obtained later, and importing its unknown IDs makes no owner lookup. Static JSON imports also fix missing seasonal source files in a clean compiled build.

The review expanded to every stored main-cup result through global season 24: **619 records across 88 countries**. Retained historical tables cover every row, and primary bracket responses independently verify the newly investigated candidates. Corrections clear attribution belonging to the wrongly listed club. The old manager's trophies are never transferred to an assumed owner.

The first comparison produced 32 corrections. The remaining 266 records received 532 successful CHPP bracket checks and independent public-table comparisons, yielding 20 more corrections. South Korea S6 remains Busan power: a renamed finalist prevents the conservative API arithmetic resolver from establishing the format, while the historical table directly identifies the stored winner. Czechia S1 remains hasek, supported by a 17–2 aggregate despite a conflicting wiki name. Exact spelling and column discrepancies are retained as source diagnostics, rather than rewritten into archive facts.

Every correction preserves unknown scores and numeric identities unless the retained evidence establishes them.

## Verification and limits

Run `npm test`, `npm run typecheck`, `npm run build`, and `npm run qa`. The numerical audit reads the database and every static dataset, checks all available API records, and recomputes frontend statistics. Instructions and independent commands are in [qa/README.md](../qa/README.md).

Final validation passed:

- **244 tests:** 218 server, 15 web, and 11 guarded data-correction tests.
- **534,450 database/static-data assertions** across 49 groups, including required absence of unexplained internal gaps.
- **28 frontend statistics groups**, covering every stored cabinet, roll, podium and election association, plus filter combinations and state regressions.
- **11,421 API requests / 76,819 assertions**, with no failures.
- **619 historical winners / 88 countries**, with zero unexplained source mismatches.
- Both-workspace typecheck, production build, diff whitespace checks, and 12 focused browser regressions passed.

The resulting archive contains 32,211 club-cup winners and 9,913 league winners. The 10,307 manager records contain 33,296 attributed titles, 149 silvers and 302 bronzes. Unknown owners remain separate from manager totals. Machine-readable suite results are in [audit-summary.json](../qa/results/audit-summary.json).

The original database and all seven static datasets are backed up under `.backup/qa-fixes-20260911/`. The repair comparison verifies that only reviewed changes were applied. Retained source evidence and exact affected records make the changes reproducible.

Missing historical manager identities, early national podium details, and the empty legacy match archive remain coverage limitations. They are never filled by guessing or represented as verified facts. The current app displays aggregate history; real historical team-match pages cannot be validated against an empty match archive. These checks do not establish that every latest competition has been synced. The changes and rebuilt data are local; deployment was outside this repair.
